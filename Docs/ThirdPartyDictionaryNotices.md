# Third-party dictionary notices

The build script generates the offline index from these public projects. Runtime lookup does not access the network.

| Data | Purpose | Source | Version and licensing notes |
| --- | --- | --- | --- |
| ECDICT | Chinese/English definitions, parts of speech, forms, frequency, exam tags | [skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) | Release 1.0.28. Repository states MIT; verify aggregated provenance for the exact version. |
| IPA-Dict | US and UK IPA | [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict) | US sources include MIT; UK provenance includes GPL data. |
| Open English WordNet | Definitions, examples, synonyms, relations | [globalwordnet/english-wordnet](https://github.com/globalwordnet/english-wordnet) | CC BY 4.0; attribution required. |

The generated index excludes personal dictionaries and Eudic originals. Local development resources are separate. Record name, version, URL, license, and generation date for new sources. Review all shipped datasets' obligations before distribution.
