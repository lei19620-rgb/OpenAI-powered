# Markdown notes

Workspace notes use Markdown as their exchange format. Notes remain stored in the app; files are explicitly imported or exported.

## Editing

- Switch between source editing and formatted preview.
- Toolbar: headings, bold, italic, checklists, bullets, quotes, and inline code.
- Preview: heading levels 1–3, quotes, lists, checklists, separators, code blocks, simple table text, and common inline formatting.
- Edits save automatically.

## Import and export

Import UTF-8 `.md` or `.markdown` files up to 2 MB. Replacing existing content requires confirmation. Import changes only the body, not course, unit, title, template snapshot, or assignment links.

Export produces UTF-8 Markdown without hidden metadata for other editors. The [daily example](../Examples/daily-learning-note.md) matches the sentence-study template, with a dynamically populated unit and creation date.
